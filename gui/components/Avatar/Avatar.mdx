# Avatar

> **Design System Reference**: Mastercard Editorial System ([DESIGN.md](file:///home/luis/mai/gui/DESIGN.md))  
> **Usage Guidelines**: [DESIGN_GUIDELINES.md](file:///home/luis/mai/gui/DESIGN_GUIDELINES.md)

## Overview
The **Avatar** component is a circular profile picture (`50% radius`) used in transaction cards, banker avatars, M&A counterparts, and co-worker lists. It uses free images from Unsplash or uppercase initials as a fallback.

## Usage Guidelines

### Do's
- Always include the `alt` attribute for accessibility.
- Use `md` as the default size to guarantee a 44x44px touch target (WCAG 2.1 AA).

### Don'ts
- Do not use images that are not profile pictures or logos.
- Do not make the radius square.

---

## Variants
- **With Image**: Displays the user's profile picture.
- **With Initials Fallback**: Displays the user's initials when an image is not available.
