# Radio

> **Design System Reference**: Mastercard Editorial System ([DESIGN.md](file:///home/luis/mai/gui/DESIGN.md))

## Overview
The **Radio** component allows mutually exclusive choices in forms and financial simulations.

## Props API

<Controls />

## Usage Guidelines

**Do's**:
- Use when the user needs to select exactly one option from a list of mutually exclusive choices.
- Ensure one option is selected by default if applicable.

**Don'ts**:
- Do not use for multiple selections (use `Checkbox` instead).
- Do not use if the choice is just a single yes/no toggle (consider a switch or single checkbox).

## Variants
- **Default**: Standard unselected state.
- **Checked**: Signal Orange ring and center dot.
- **Disabled**: Greyed out, unclickable state.
