## Usage Guidelines

### Do's
- Use the Spinner to indicate asynchronous operations, such as data fetching or agent 'thinking' states.
- Match the Spinner variant to the surrounding context (e.g., `cream` for dark backgrounds).

### Don'ts
- Do not use Spinners for instant actions.
- Do not place multiple Spinners in close proximity.

---

## Variants
- **Signal Orange**: Default primary loading state.
- **Ink Black**: Dark variant for light backgrounds.
- **Canvas Cream**: Light variant for dark backgrounds.
