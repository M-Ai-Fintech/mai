## Overview
The **Divider** component is a subtle horizontal separating line used in containers and tables to structure content visually.

## Usage Guidelines

### Do's
- Use spacing variants to properly separate different sections.
- Use dashed variants for secondary visual breaks.

### Don'ts
- Do not use dividers excessively within the same container.
- Do not use dividers for layout structures that can be achieved with margin or padding.

---

## Variants
- **Solid**: Standard horizontal line.
- **Dashed**: Dashed horizontal line.
