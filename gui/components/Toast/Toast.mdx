## Usage Guidelines
- **Do**: Use to display brief, non-interruptive notifications.
- **Do**: Keep messages short and concise.
- **Don't**: Use for critical errors that require immediate user action; use a modal instead.

## Variants
The Toast component supports four variants: `info`, `success`, `warning`, and `error`.
