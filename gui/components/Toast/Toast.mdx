# Toast

> **Design System Reference**: Mastercard Editorial System ([DESIGN.md](file:///home/luis/mai/gui/DESIGN.md))

## Overview
The **Toast** component provides floating notifications for asynchronous feedback from APIs and the 7 ADK agents.

<Controls />

## Usage Guidelines
- **Do**: Use to display brief, non-interruptive notifications.
- **Do**: Keep messages short and concise.
- **Don't**: Use for critical errors that require immediate user action; use a modal instead.

## Variants
The Toast component supports four variants: `info`, `success`, `warning`, and `error`.
