# Navigation Suite (TopBar & Sidebar)

> **Design System Reference**: Mastercard Editorial System ([DESIGN.md](file:///home/luis/mai/gui/DESIGN.md))

## Overview
The **Navigation Suite** combines the contextual `TopBar` (breadcrumbs, POV selector) and the retractable `Sidebar` with layered submenus.

## Usage Guidelines
- **Do**: Keep navigation items clear and concise.
- **Do**: Ensure responsive behavior (e.g. hamburger menu) works seamlessly on smaller viewports.
- **Don't**: Overload the sidebar with too many deep nested items.
