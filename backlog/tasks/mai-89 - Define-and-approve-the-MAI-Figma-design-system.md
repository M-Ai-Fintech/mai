## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Delivery step 1 of the MAI-85 initiative.

Create one shared, versioned Figma design source as the sole visual and interaction authority for the MAI banker workspace.

Define the Figma file and page organization, variables, styles, primitives, components, patterns, responsive behavior, accessibility rules, content rules, and engineering handoff. Existing GUI assets, gui/DESIGN.md, Storybook components, and Stitch artifacts may be inspected for evidence but are not compatibility constraints.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 An accessible, versioned Figma file or project is linked from this task and identified as the sole visual and interaction design source.
- [ ] #2 Variables and styles cover semantic color, typography, spacing and sizing, grids and breakpoints, radii, elevation, and motion.
- [ ] #3 The component architecture covers primitives, forms, navigation, data display, feedback, and overlays with named variants, states, and responsive constraints.
- [ ] #4 Component anatomy, naming, Auto Layout and constraint behavior, composition rules, and usage guidance are documented.
- [ ] #5 Accessibility and content rules cover contrast, focus, keyboard behavior, touch targets, validation, and status communication.
- [ ] #6 The approved system does not require compatibility with Stitch or the current GUI implementation.
- [ ] #7 Product and design approval is recorded with unresolved findings resolved or explicitly tracked.
<!-- AC:END -->
