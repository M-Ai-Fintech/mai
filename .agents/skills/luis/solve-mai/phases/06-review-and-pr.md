# Review and PR

1. Invoke `$model-selection` for review.
2. Review the final diff, task scope, tests, generated artifacts, and documentation.
3. Commit focused changes only after verification. Push and create a PR only when the owner authorized remote mutation.
4. Include task ID, summary, tests, risks, and manual steps in the PR.
5. Request human review from the owner. The agent does not approve or merge its own PR.

Completion: a human-reviewable PR is available, or the precise reason no PR exists is recorded.
