# Investigation

Use only when the symptom, ownership, or minimal solution is uncertain.

1. Invoke `$model-selection` for investigation, then `$investigate`.
2. Compare the task's intended behavior to the end-to-end code path.
3. Record root cause, rejected hypotheses, minimal solution, and regression test in Backlog notes.
4. For environment, provider, VDR, Gemini, or dependency configuration defects, invoke `$config-bug-closure` before finalization.

Completion: one evidence-backed implementation path is selected; otherwise report the blocker.
